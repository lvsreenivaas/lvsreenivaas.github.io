# lvsreenivaas.github.io

Personal site of Venkata Sreenivaas Lingam — quantitative research and trading.
Live at **https://lvsreenivaas.github.io**

Static HTML, no framework, no build step on the server. GitHub Pages serves `main` from the
repository root.

## Editing

Pages are generated by `build.py`, which owns the shared `<head>`, nav, footer, JSON-LD and the
inline-SVG charts.

```sh
python3 build.py          # regenerates every .html, robots.txt and sitemap.xml
python3 -m http.server     # preview at http://localhost:8000
```

**Edit `build.py`, not the generated `.html` files** — the next build overwrites them.

## Layout

| Path | What it is |
|---|---|
| `build.py` | Page generator: content, templates, chart helpers, page registry |
| `index.html` … `404.html` | Generated output — do not hand-edit |
| `assets/style.css` | Hand-written stylesheet (not generated) |
| `assets/` | Images, résumé and paper PDFs, favicon, Open Graph card |
| `robots.txt`, `sitemap.xml` | Generated |
| `.nojekyll` | Serve files verbatim; skip Jekyll processing |

## Configuration

Three placeholders near the top of `build.py` are inert until filled in:

- `GA4_ID` — Google Analytics 4 measurement ID. No analytics script loads while it contains `X`.
- `GSC_TOKEN` — Google Search Console HTML-tag verification token.
- `FORMSPREE` — contact form endpoint. The form tells visitors to email directly until set.

Change one, re-run `python3 build.py`, commit.

## Charts

Charts are inline SVG generated in `build.py` — no charting library and no CDN. The categorical
palette (`#3987e5` / `#d95926` / `#199e70`) was validated for colour-blind separation, lightness,
chroma and contrast against the chart surface `#060B16`. Chart surfaces are kept opaque rather
than translucent over the animated background, so that validation stays true. Re-validate before
changing any series colour.
